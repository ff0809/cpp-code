
HSV颜色检测与边缘识别工具 使用说明

【功能简介】
本程序基于 OpenCV 实现，提供图像或摄像头输入的颜色分割与轮廓提取功能。
支持手动拖动滑块设置 HSV 阈值，查看掩膜、边缘和轮廓效果图。

【主要功能】
1. 支持打开摄像头实时检测或加载静态图片
2. 通过滑块调整 HSV 参数进行颜色分割
3. 自动绘制边缘、轮廓以及目标矩形框
4. 多窗口显示处理各个阶段的图像

【使用说明】
程序启动后，会提示选择输入来源：
- 输入 1：选择图像文件（需手动输入路径）
- 输入 2：开启摄像头进行实时检测

【窗口说明】
- Trackbars：HSV 参数滑动条
- Color Range：显示当前颜色渐变条
- Original：原始图像或视频帧
- Mask：颜色掩膜（白色区域为目标）
- Result：掩膜后的原图
- Edges：边缘检测图（Canny）
- Contours：绘制轮廓和矩形的最终结果

【滑动条参数】
- Hue Min/Max：色相范围（0-179）
- Sat Min/Max：饱和度范围（0-255）
- Val Min/Max：亮度范围（0-255）

【操作方式】
- 拖动滑块实时更新处理效果
- 按 ESC 键退出程序

【提示】
- 建议先调整色相（Hue）定位颜色，再调整饱和度和亮度以获得最佳掩膜
- 检测区域较小将不会绘制矩形（面积需 > 1000）
- 可参考 Color Range 渐变条和 Mask 图帮助调试参数

【退出方式】
- 在任意界面按下 ESC 键即可关闭所有窗口并退出程序
